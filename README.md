# PORTFOLIO BACKEND

### INTRODUCTION
The **portfolio-backend** repository houses the core services for a user-driven portfolio website builder. It provides the **API endpoints** and **business logic** necessary to **store, manage, and retrieve** all portfolio-related details. This backend service is crucial for enabling users to easily fill in their information and generate their personalized portfolio website.

### PREREQUISITE

Before installing the dependencies of project, make the `.env` file for your project from the `.env-sample` file present in the project's root directory. 

### INSTALLATION
Please run the following commands to install the necessary dependencies of this project. Please keep in mind that `Node.js` should be installed in your system prior running the following commands. 

```sh
  npm install
  npm run build
```

Once the build command runs, a build folder will appear in your project directory. Now, run the following command to start the project.

```sh
  npm start
```
